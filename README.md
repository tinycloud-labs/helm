# Helm Charts

Helm charts for the TinyCloud Labs homelab.

**Browse the charts: [tinycloud-labs.github.io/helm](https://tinycloud-labs.github.io/helm)**

```bash
helm repo add tinycloud-labs https://tinycloud-labs.github.io/helm
helm repo update
```

Charts are released from [`charts/`](charts) on every merge to `main`, which also updates the page above.
